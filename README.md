# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/6df81a98-f427-4fbd-87cb-86cb1fd4c446

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Deploy to Vercel

Configure these environment variables in the Vercel project settings:

- `VITE_FIREBASE_API_KEY`
- `VITE_FIREBASE_APP_ID`
- `VITE_FIREBASE_AUTH_DOMAIN`
- `VITE_FIREBASE_MESSAGING_SENDER_ID`
- `VITE_FIREBASE_PROJECT_ID`
- `VITE_FIREBASE_FIRESTORE_DATABASE_ID`

`VITE_FIREBASE_STORAGE_BUCKET` and `VITE_FIREBASE_MEASUREMENT_ID` are optional. The serverless backend reads Firebase settings from `process.env`; it does not load `firebase-applet-config.json`.
